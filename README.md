# spkeep — Download X Space Recordings

Promotional articles for [spkeep.com](https://spkeep.com/), a free tool to download X (Twitter) Space audio recordings as .m4a files — no login, no app install. Paste a Space link, check the info, download the audio. Also offers transcripts and AI summaries, in the Space's language.

This repo holds one article per language (12 languages), each introducing the site, how to download a Space recording with it, the hosts whose Spaces are archived on it, and some of the most popular archived Spaces.
